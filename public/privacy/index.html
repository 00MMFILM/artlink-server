개인정보 처리방침 / Privacy Policy

최종 수정일: 2026년 10월 30일 / Last updated: October 30, 2026

1. 수집하는 개인정보 / Information We Collect

이름, 이메일, 프로필 정보 (성별, 생년월일, 키, 특기 등), 이용자가 생성한 콘텐츠 (연습 노트, 이미지, 영상, 음성 녹음 및 그 텍스트 변환본)

Name, email, profile information (gender, date of birth, height, skills, etc.), user-generated content (practice notes, images, videos, voice recordings, and their text transcriptions)

2. 수집 목적 / Purpose of Collection

서비스 제공 및 개선, 매칭 기능 지원.

Service provision and improvement, matching feature support.

2-1. AI 학습 활용 및 동의 / AI Training Use and Consent

이용자가 학습 활용에 동의한 경우에 한하여, 동의한 회원의 연습 노트·음성·영상(및 첨부 사진)을 아트링크 AI 학습에 사용합니다. 해당 원본은 비공개(private)로 안전하게 보관되며 외부에 공개되지 않고, 학습 활용 시 개인 식별 정보는 분리·비식별 처리됩니다. 동의하지 않으면 원본은 보관되지 않으며, 이용자는 설정에서 언제든 동의를 철회하고 보관된 데이터를 삭제할 수 있습니다.

Only when the user consents, the practice notes, voice, and video (and attached photos) of consenting members are used for ArtLink AI training. Such originals are stored securely in a private, non-public archive, and personal identifiers are separated and de-identified before any training use. Without consent, no originals are archived, and users can withdraw consent and delete the archived data at any time in Settings.

2-2. 웹 작업실에서 앱으로 가져오기 / Web Studio Transfer

웹 작업실의 사진·영상·음원 파일은 자동 전송하지 않습니다. 이용자가 전송 미리보기를 확인하고 동의한 글·메모·비교 설정만 앱으로 가져오기 위해 암호화하여 임시 보관합니다. 코드는 24시간 동안 유효하며, 코드를 아는 사람은 해당 기록을 가져올 수 있습니다. 웹에서 코드를 취소할 수 있고, 만료된 임시 사본은 매시간 실행되는 정리 작업으로 삭제합니다. 서비스 요청 제한을 위해 IP 주소 자체 대신 매일 바뀌는 해시를 최대 약 25시간 보관합니다. 이 전송 사본은 AI 학습에 사용하지 않습니다. 앱에 저장한 기록은 앱의 삭제·동기화 설정을 따릅니다.

Original image, video and audio files are not automatically transferred. Only the text, notes and comparison settings you preview and consent to are temporarily stored encrypted for import. Codes are valid for 24 hours; anyone with a code can import that review. You can revoke a code on the web. An hourly cleanup removes expired temporary copies. Request throttling uses a daily changing hash rather than the raw IP address, retained for up to approximately 25 hours. Transfer copies are not used for AI training. Notes saved in the app follow its deletion and sync controls.

녹음 구간 점검 / Recording checks

녹음 구간 점검을 선택하고 동의하면 선택한 짧은 녹음과 기준 대사를 서버로 전송합니다. 소리 크기·조용한 구간을 계산하며, 서버의 임시 음성 파일은 처리가 끝나면 삭제합니다. 발음 평가가 활성화된 경우 Microsoft Azure Speech에도 녹음과 대사를 전송합니다. 이 기능은 학습용 원본 보관에 자동 동의시키지 않습니다. 계정·요청 식별자·요청 시간·완료 여부는 이용 한도 관리에 사용하며, 지난 이용 이력은 다음 점검 요청 시 정리되고 회원 탈퇴 시 함께 삭제됩니다. 상세 분석 결과는 화면에만 있으며 사용자가 노트에 추가한 요약은 기존 노트 보관·동기화 정책을 따릅니다.

With your consent, recording checks send the selected short recording and reference line to the server to measure signal levels and quiet intervals. Temporary server audio is deleted after processing. When pronunciation assessment is enabled, the recording and line are also sent to Microsoft Azure Speech. This does not opt you into storage of training originals. Account/request identifiers, request time and completion status are used for usage limits; old usage records are cleaned on your next check and removed on account deletion. Detailed results stay in the screen; summaries you choose to add to a note follow existing note storage and sync controls.

한국어 말투 비교 / Korean Delivery Comparison

말투 비교에 동의하면 선택한 짧은 녹음과 한국어 대사를 아트링크 서버에 전송합니다. 직접 선택한 기준 음성도 비교를 위해 전송되며, 이용자는 해당 음성을 분석에 사용할 권한이 있어야 합니다. 음성은 OpenAI의 음성 인식 서비스에 보내 말한 내용과 단어별 시간을 확인하고, 아트링크 서버는 두 녹음의 음높이 변화와 상대적 구간 길이를 계산합니다. 기본 연습 음성은 AI 합성 음성으로 공인 표준 발음 자료가 아닙니다. 이 기능은 발음·사투리의 정오를 판정하지 않습니다.

서버 임시 음성 파일은 처리 후 삭제하며, 분석용 음성·변환 텍스트·음높이 곡선은 아트링크 데이터베이스에 저장하지 않습니다. OpenAI의 처리·보관에는 해당 제공자의 API 데이터 정책이 적용됩니다. 비교 이용 이력은 위 녹음 구간 점검과 같은 한도 관리 정책을 따릅니다. 분석 동의는 학습 활용 동의와 별개입니다. 상세 결과는 현재 화면에서만 표시되며, 이용자가 노트에 추가하고 저장한 연습 요약은 기존 노트 정책을 따릅니다.

With consent, selected short recordings and the Korean reference line are sent to ArtLink. If you supply a reference recording, it is also sent for comparison and you must have permission to use it. Audio is sent to OpenAI speech recognition to identify words and timestamps. ArtLink computes pitch movement and relative segment duration. Built-in practice voices are AI-generated and are not certified standard-pronunciation material. This feature does not judge whether a dialect or pronunciation is correct.

Temporary server audio files are deleted after processing. Analysis audio, transcripts and pitch curves are not stored in the ArtLink database. OpenAI processing and retention follow its API data policies. Usage records follow the recording-check policy above. Analysis consent is separate from training consent. Details remain on the current screen; practice summaries you add to and save in a note follow existing note policies.

3. 보관 기간 / Retention Period

계정 삭제 시까지. 이용자는 언제든지 프로필 > 계정 삭제를 통해 모든 개인정보를 삭제할 수 있습니다.

Until account deletion. Users can delete all personal information at any time through Profile > Delete Account.

4. 제3자 제공 / Third-Party Sharing

녹음 점검과 한국어 말투 비교는 위에 설명한 분석 제공자에게 이용자가 동의한 자료를 전송합니다. 선택한 기능과 제공자에 따른 전송 범위·보관 방식은 각 기능 안내를 따릅니다.

Recording checks and Korean delivery comparison send consented data to the analysis providers described above. The data sent and retention practices depend on the selected feature and provider, as explained in each feature notice.

5. 광고 / Advertising

본 앱은 Google AdMob을 통해 광고를 표시할 수 있습니다. AdMob은 광고 개인화를 위해 기기 식별자를 수집할 수 있습니다.

This app may display ads through Google AdMob. AdMob may collect device identifiers for ad personalization.

6. 데이터 보안 / Data Security

아트링크는 Supabase 인증과 데이터베이스를 사용합니다. 음성 비교 요청은 로그인한 계정으로 확인하며, 이용 횟수 기록은 서버에서만 접근할 수 있습니다. 음성 분석에 사용한 서버 임시 파일은 처리 후 삭제합니다.

ArtLink uses Supabase authentication and a database. Speech comparison requests are authenticated, and usage records can only be accessed by the server. Temporary server audio files are deleted after processing.
